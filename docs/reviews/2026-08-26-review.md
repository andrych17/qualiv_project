## A.1 — Gejala

7 test gagal acak (`LegalDueDiligenceTest`, `LegalTaxTest`, `LegalWillTest`, `WorkflowMessagingEngineTest`, `WorkflowPreferenceCenterTest`, `WorkflowSlaEscalationTest`×2), semua exception identik:

```
SQLSTATE[42501]: permission denied to terminate process
DETAIL: Only roles with the SUPERUSER attribute may terminate processes of roles with the SUPERUSER attribute.
```

Posisi error: `tests/Concerns/SetsUpTenant.php` → `dropTenantDatabaseIfExists()`.

## A.2 — Akar masalah (dibuktikan via log Postgres shared-postgres)

Shared instance Postgres dipakai beberapa stack (`TrdRetail1`, `gms`, dll.) dan punya client GUI/backup yang **auto-connect sebagai role superuser `postgres` ke setiap database baru** — termasuk `tenant_001` yang baru dibuat test. Teardown tidak berhak kill backend superuser → drop gagal → test gagal. Intermitten, mengikuti momen GUI reconnect.

Faktor pembanding: `tests/TestCase.php::createApplication()` menimpa env phpunit.xml secara hardcoded (`DB_USERNAME => 'nusaevo'`) — mengubah `phpunit.xml` saja **tidak berefek**. Ini yang membuat diagnosis awal menyesatkan.

## A.3 — Perbaikan (3 file diedit — BELUM di-commit)

1. Role test khusus di instance: `CREATE ROLE nusa_test LOGIN PASSWORD 'secret' SUPERUSER CREATEDB;`
2. `tests/TestCase.php` — `DB_USERNAME` → `getenv('TEST_DB_USERNAME') ?: 'nusa_test'`.
3. `tests/Concerns/SetsUpTenant.php` — ganti `pg_terminate_backend()` manual dengan satu statement `DROP DATABASE IF EXISTS "..." WITH (FORCE)` (PG13+, server = PG 16.14).
4. `phpunit.xml` — `DB_USERNAME` → `nusa_test` (selaras; sebenarnya ditimpa TestCase).
